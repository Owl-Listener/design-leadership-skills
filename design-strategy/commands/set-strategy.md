# /set-strategy
Develop a design strategy from vision to bets.
## Steps
1. **Cast the vision** — Articulate the future state using `design-vision` skill.
2. **Write the strategy** — Name the bets and the not-doing using `design-strategy-doc` skill.
3. **Set the guardrails** — Define principles to guide decisions using `org-design-principles` skill.
4. **Allocate** — Prioritise capacity across the portfolio using `prioritisation-at-scale` skill.
## Output
A strategy pack: vision, strategy doc with explicit bets, design principles, and a portfolio allocation.
Consider following up with `/make-the-case` to fund the bets.
