# /make-the-case
Build a fundable case for design investment.
## Steps
1. **Anchor on strategy** — Tie the ask to bets using `design-strategy-doc` skill.
2. **Build the case** — Frame opportunity, ask, return, cost of inaction using `investment-case` skill.
3. **Show the trade-off** — Demonstrate portfolio impact using `prioritisation-at-scale` skill.
## Output
An investment case: business framing, a specific ask with options, expected return, and the cost of inaction.
Consider following up with `/build-narrative` to bring stakeholders along.
