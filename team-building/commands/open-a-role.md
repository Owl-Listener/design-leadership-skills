# /open-a-role
Open a design role with a fair, well-designed process.
## Steps
1. **Place the role** — Decide where it sits using `team-topology` skill.
2. **Write the spec** — Draft an inclusive job spec using `job-spec` skill.
3. **Design the loop** — Build a signal-rich interview loop using `hiring-loop` skill.
4. **Set the rubric** — Define portfolio evaluation using `portfolio-review` skill.
## Output
A hiring pack: role placement, job spec, interview loop, and a portfolio rubric.
Consider following up with `/onboard-hire` once you've made an offer.
