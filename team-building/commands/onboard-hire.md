# /onboard-hire
Set a new hire up to thrive in their first 90 days.
## Steps
1. **Plan the 90 days** — Build a 30/60/90 arc using `onboarding-plan` skill.
2. **Set the culture** — Make team norms explicit using `psychological-safety` skill.
3. **Map their growth** — Sketch early development using `team-topology` skill.
## Output
An onboarding plan: a 30/60/90 arc, the norms to convey, and where the role fits the team.
Consider following up with `/prep-one-on-one` to start the relationship well.
