# /set-cadence
Design the operating system the org runs on.
## Steps
1. **Set planning layers** — Nest annual to weekly using `planning-cadence` skill.
2. **Define decisions** — Assign decision rights using `decision-framework` skill.
3. **Design leadership rhythm** — Set the forums that run the org using `operating-rhythm` skill.
4. **Build in delegation** — Push ownership down using `delegation-model` skill.
## Output
An operating cadence: nested planning layers, decision rights, a leadership rhythm, and a delegation model.
Consider following up with `/run-design-review` to add quality gates.
