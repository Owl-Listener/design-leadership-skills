# /run-design-review
Stand up reviews that raise quality without bottlenecking.
## Steps
1. **Design the system** — Tier reviews and set the bar using `design-review-at-scale` skill.
2. **Clarify rights** — Decide who reviews and who decides using `decision-framework` skill.
3. **Delegate ownership** — Distribute reviewing using `delegation-model` skill.
## Output
A review system: tiered reviews, a shared bar, clear decision rights, and distributed reviewer ownership.
Consider following up with `/set-cadence` to slot reviews into the wider rhythm.
